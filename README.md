# Jukebox
Jukebox is a web-based music player that allows users to add songs, navigate between tracks, and manage their playlist.
i used html, css, javascript for the web

# Description
it is a music web player that can play custom audio in your local files with any audio file type, it also has a very cool design near the header " MUSIC PLAYER " i have built this web with HTML CSS and JS only

## Tech Stack

- **HTML5** – Structures the music player interface and audio controls.
- **CSS3** – Handles the layout, styling, and visual design of the application.
- **JavaScript** – Manages music playback, playlist interactions, track navigation, and user controls.
- **HTML Audio API** – Enables audio playback directly in the browser.

### Development Tools

- **Git** – Version control.
- **GitHub** – Source code hosting and repository management.
- **Antideploy** – Website hosting and deployment.

### Project Structure

- `index.html` – Main application structure.
- `styles.css` – Styling and layout.
- `script.js` – Music player functionality.
- `music/` – Directory for music files.

# Getting Started
Open the Jukebox website in your browser.

Use the Add Songs option to select audio files.

Select a song from the playlist to play it.

Use the Previous button to go to the previous track.

Use the Next button to move to the next track.

Select another song from the playlist to switch tracks.

## Help

If you encounter any issues while using Jukebox, follow these steps:

1. Make sure you are using an up-to-date web browser.
2. Check your internet connection if the website or music does not load.
3. Refresh the page and try again if the music player stops responding.
4. If music files are not playing, check whether the files are accessible and supported by your browser.
