# Jukebox
Jukebox is a web-based music player that allows users to add songs, navigate between tracks, and manage their playlist.
i used html, css, javascript for the web

# Getting Started
Open the Jukebox website in your browser.

Use the Add Songs option to select audio files.

Select a song from the playlist to play it.

Use the Previous button to go to the previous track.

Use the Next button to move to the next track.

Select another song from the playlist to switch tracks.
